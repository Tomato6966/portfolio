# My Personal Portfolio

Welcome to my personal portfolio website! This project showcases my work, skills, and experience as a developer. Built with Next.js, it's designed to be a clean, modern, and responsive platform to present my projects and connect with others.

## Features

*   **Dynamic Project Display:** Fetches and displays my GitHub repositories, providing an up-to-date view of my open-source contributions.
*   **Interactive UI Components:** Includes custom-built interactive elements like a typing text effect and responsive navigation.
*   **Modern Styling:** Utilizes Tailwind CSS for a utility-first approach to styling, ensuring a consistent and maintainable design.
*   **Optimized Performance:** Leverages Next.js features for image optimization, font optimization, and fast page loads.
*   **Responsive Design:** Adapts seamlessly to various screen sizes, from desktops to mobile devices.

## Technologies Used

*   **Framework:** Next.js (React Framework)
*   **Styling:** Tailwind CSS, PostCSS
*   **Language:** TypeScript
*   **Package Manager:** Bun (or npm/yarn/pnpm)
*   **Version Control:** Git

## Getting Started

Follow these steps to get a local copy of the project up and running on your machine.

### Prerequisites

Make sure you have the following installed:

*   Node.js (LTS version recommended)
*   Bun (or npm/yarn/pnpm)
*   Git

### Installation

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/YOUR_USERNAME/YOUR_REPOSITORY_NAME.git
    cd YOUR_REPOSITORY_NAME
    ```
    *(Replace `YOUR_USERNAME` and `YOUR_REPOSITORY_NAME` with your actual GitHub username and repository name)*

2.  **Install dependencies:**
    ```bash
    bun install
    # or
    npm install
    # or
    yarn install
    # or
    pnpm install
    ```

### Running the Development Server

To start the development server:

```bash
bun dev
# or
npm run dev
# or
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result. The page auto-updates as you edit the files.
